# 飞书工作待办助手

这是独立安装的通用技能。先读取 [安装与能力核验](references/installation.md)。账号、应用、表格、通知收件人都在当前使用者初始化时产生；包内没有预设账号或任何人的工作记录。

## 在线规则与样式

1.1.0起支持GitHub配置订阅。先运行 `scripts/online_config.py sync`，读取输出的 `rules_file` 与 `effective_config`。每次整理必须使用本次同步后的有效规则；仅同步文件而不阅读，不算应用了新的提取规则。安装包已有更新源时自动使用；没有时按 [在线更新说明](references/online-updates.md) 绑定使用者选择的仓库。

远程配置仅控制扫描时间窗、休闲群关键词、提取指导、摘要长度及卡片颜色/文字/标签顺序。它不授权扩大账号或会话范围，不改变完成确认、收件人、数据表归属或宿主权限，不含可执行代码；安装、定时、回调与个人授权仍按本地规则核验。网络失败/配置无效时沿用有效缓存，并如实报告警告。个人 `local-preferences.json` 覆盖公共默认配置。

## 首次安装

1.2.0提供本机手动入口：初始化后生成桌面“飞书待办控制台”，安装包内也有Open-Control-Panel.command（macOS）/ .cmd（Windows）/ .sh（Linux）。详见[控制台与开关](references/control-panel.md)。不要因为用户询问开关位置就代其停止助手；只有明确要求执行启停时才操作。

每次日常任务先运行 `python3 scripts/control_panel.py status`。若enabled=false，当次直接结束，不同步聊天、不提取、不写入、不发送、不恢复接收进程，也不擅自把开关打开。包内脚本有同样的硬性检查。关闭是个人本机设置，GitHub配置无权覆盖。

使用 `scripts/manage.py doctor` 检查当前机器自己的 CLI 与身份。没有独立授权时，按安装参考引导本人完成授权。用户说“安装并初始化我的待办助手”即授权为本人创建空白待办表、仪表盘和配套统计流程；不等于允许读其他人的账号或处理业务事项。

确认当前使用者身份后，运行 `scripts/manage.py init --confirm`。该脚本会生成个人空白台账、视图、日期/月度分类、完成/重新打开流水、每日/每周趋势仪表盘。脚本在当前用户的应用数据目录保存绑定，不写进技能包。

新的1.2安装初始化完成后默认关闭，生成入口不会自动启动接收或发送。本人从控制台点击“开启助手”后，按安装指南继续验证卡片提交和定时。旧安装升级保留已有开关与所有业务记录；1.1没有开关文件时保留其原有运行约定，升级与重新部署接收代码须明确执行。

聊天卡片的批量勾选需要当前应用的 `card.action.trigger` 和独立接收进程；定时整理需要宿主实际可运行的调度能力。按参考逐项核验，未验证时不能把“技能已导入”说成“全套已启用”，不能发送看似可保存但没有接收端的按钮。

## 整理工作聊天

按 [每日整理与清单规则](references/daily.md) 执行：先同步在线规则与真实勾选，再收集消息证据，分析本人责任、合并去重，写入变更，最后发给本人。默认首次看近15天，之后增量并回溯48小时；实际时间窗以有效配置为准，已完成台账一直保留。读消息前排除所有话题群、机器人私聊和明显休闲群。

用 `scripts/collect.py` 收集证据，再由当前 AI 宿主分析其生成的文件。收集脚本不使用额外模型账号，也不会凭关键词自动判断任务归属。根据 [数据输入协议](references/task-input.md) 生成 JSON 提案，运行 `scripts/manage.py upsert <提案路径>`。只在证据完整审核后调用 `finish-scan` 保存水位。

“本人职责”与“进展”分开：标签可以是由你执行、由你确认、由你复核，也可以根据真实需要扩展为由你协调、由你跟进等。别人修改、本人验收时，不能写成催本人修改。职责不明用灰色“职责待确认”，不默认由本人执行。新增实际选项前读取字段并只追加；`option-add --field 本人职责 --name <标签> --confirm` 保留原定义和所有旧值。

## 通知和完成

使用 `scripts/send_batch_card.py --batch daily-YYYY-MM-DD --not-before 10:00` 发当天唯一一张清单，日期取北京时间。默认工作日09:40准备、10点发送，可按使用者偏好修改。到点前等待，到点后再次同步完成状态。收件人取当前安装绑定的本人；脚本会拒绝切换到别的 CLI 用户或应用。

默认每项为彩色职责标签＋加粗名称，下方 `• 截止：...` 和 `• 下一步：...`；文字与展示开关以有效配置为准。日期用 YYYY-MM-DD，未明确日期按配置展示，完整背景放表中，不堆括号。单卡多选后一次确定，接收进程仅处理本人在已登记卡片的提交；未选项不写 false，重复回调不重复处理。

完成状态只来源于本人明确确认或表格勾选。第三方说“我改好了”只能触发本人复核，不代表本人复核已完成。根据当前台账和真实完成/重新打开流水计算趋势，不从消息日期猜完成时间。辅助编号以 `__` 开头，不进入通知与真实统计。

## 维护边界

凭证由使用者自己的飞书 CLI 管理，不能写入技能、发给分享者或复制给同事。运行时的 `state.json`、cards、evidence、日志和用户进程配置不属于可转发的技能内容。

宿主或企业权限不支持某能力时，说明具体缺项；不要绕过管理员要求、复用分享者应用、编造定时任务或静默改为其他收件人。当前模型可处理的普通表格/消息操作继续完成，不因一项能力欠缺而声称其他能力都不可用。
