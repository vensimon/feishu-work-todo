# 通过AI对话暂停和恢复

使用者可以直接说“暂停待办助手”“关闭待办助手”或“恢复待办助手”。仅在本人明确要求执行时操作；问怎么关闭、讨论入口、让你删除包内功能，都不代表要暂停当前系统。

## 查询

运行 `python3 scripts/service.py status`。它只读取当前安装状态，不请求飞书授权、不启动接收器、不创建桌面或网页入口。

## 暂停

本人明确要求暂停整套助手时：

1. 运行 `python3 scripts/service.py pause --confirm`。暂停本人的聊天收集、提案写入、通知与卡片勾选保存，停止当前安装的接收器，保留表格和全部记录。无需有效飞书登录即可暂停本机操作。
2. 从当前安装state.host_schedule查找已登记的宿主任务，用当前AI宿主实际的调度工具暂停对应任务，并读回验证；不要操作其他安装或不相关任务。已获得“暂停助手”的指示，不必再问一次是否暂停同一任务。
3. 运行status核对本机已暂停、接收器已停止。宿主无暂停能力或找不到原任务时说明具体未完成项；本机已暂停后，原任务即使唤起也须先读enabled并跳过业务，不能把“跳过”说成“调度已暂停”。

用户只要求停每日提醒时，按其范围暂停通知调度，不擅自关闭其他能力。已送达的消息保留；已发出的外部请求不能靠暂停撤回。

## 恢复

本人明确要求恢复时，先读取现有绑定与状态，运行 `python3 scripts/service.py resume --confirm`，核验当前接收器版本及连接。恢复失败会保持暂停；不要清空记录或重新初始化表格。原有授权失效时按安装指南处理，不复用别人的身份。

再通过宿主工具恢复此前暂停的已登记任务并读回，不重复创建调度。若尚未配置调度，说明手动可用、定时待配置。回调探针尚未验证时按安装指南验证，不能将进程启动成功等同卡片已能保存。

## 升级

1.4安装包不再包含网页控制台、HTTP服务或桌面启动文件。保留个人运行目录，替换技能包即可；旧桌面快捷方式可自行删除。旧宿主任务若写死control_panel.py status，须更新为service.py status；引用当前技能的任务按新规则执行。询问升级时不能顺手执行暂停或恢复。
